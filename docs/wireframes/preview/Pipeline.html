How a requested term gets published

Step 1 · App
User requests a term

From the search page when a term isn’t found.

→
Step 2 · GitHub
GitHub issue created

Labelled term-request, with the term and context.

→
Step 3 · Claude
Writer agent

Validates it’s a real US term, researches, writes the full entry.

→
Step 4 · Claude
Reviewer agent

Checks accuracy and format. Sends it back to the writer if needed.

→
Step 5 · Keystatic + Vercel
Publish

Commits the content file with the AI tag. Vercel redeploys. Issue closed.
